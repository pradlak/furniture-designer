Panel cutting at meble.pl from a CSV file

The panel-cutting service of meble.pl (a Polish online board shop that cuts and edge-bands boards to order) lets you load a cut list from a file instead of typing in each piece by hand. The furniture designer saves such a file straight from your 3D design — you just load it.

How to save the file for meble.pl

  1. Design your furniture in the designer.
  2. Click 💾 Cut list…, choose the meble.pl format and tick what to export (e.g. cabinets and HDF backs).
  3. In the file window click 💾 Save next to each board — each board (decor) is a separate file.
  4. On meble.pl open the right cutting service, choose the board and click „Wczytaj listę formatek z CSV” (load the cut list from CSV). Check the data after loading.

Which meble.pl cutting service to choose

Board in the designCutting service at meble.pl
Chipboard (melamine-faced) — sides, top/bottom panels, shelves, railsPłyty meblowe (furniture boards)
HDF — backsPłyty budowlane (construction boards)

Lacquered MDF fronts and fillers, and worktops, are ordered differently — they don't go into the meble.pl files, but they are on the cut list in Excel.

File format

The file uses semicolons as the separator and has the columns in the same order as a file exported by meble.pl itself:

ColumnWhat it means
Namethe part and the piece of furniture, e.g. „Left side (Left cabinet)” — doesn't affect the cutting
Width / Heightshorter / longer side of the piece in mm
Width / height banding= both edges of that side, - one, empty — no banding
Board thicknessin mm, e.g. 18.00
Quantityidentical pieces are merged
Grain1 — along the height (furniture boards), 0 — doesn't matter (HDF)

An example row: Back (Cabinet 1);500;;500;;3.00;1;0; — an HDF back of 500 × 500 mm, no banding, 1 piece, grain doesn't matter.

What to watch out for

  • Piece size limits — meble.pl cuts pieces from 240 × 100 to 2500 × 1200 mm. The designer lists the ones that don't fit.
  • Size including banding — the file contains the finished size of the piece. On your first order, compare one banded piece after loading with the list in Excel.
  • Plain board — with a white board you can set the grain to „doesn't matter” on meble.pl; the cutting service will rotate the pieces and use less board.
